International Journal of Computing and Digital Systems (IJCDS)  ·  August 2026

Real-Time Sign Language Recognition Using CNN and MediaPipe with Enhanced Background Adaptation and Contextual Translation

  • Developed a real-time sign language recognition system combining CNN classification with MediaPipe hand-landmark extraction, achieving 97–99% accuracy at sub-100ms inference latency for the Deaf and hard-of-hearing community.
  • Designed a background adaptation mechanism that maintains recognition accuracy under variable lighting and cluttered environments — the primary failure mode for gesture models deployed in the real world.
  • Implemented contextual translation that converts isolated hand signs into grammatically meaningful phrases rather than isolated characters, significantly improving practical usability.
  • Evaluated across diverse lighting conditions, skin tones, and backgrounds to validate robustness; published in the International Journal of Computing and Digital Systems (IJCDS), August 2026.

Visual Inspection Agent

  • Developed an industrial visual inspection application in collaboration with Tata Technologies, deploying a YOLOv8 model that localises and classifies defects in real time — an agentic decision layer routes each detection to re-inspect, escalate for human review, or pass, replacing the manual bottleneck entirely.
  • Engineered robustness against severe class imbalance, sensor noise, and variable factory lighting through targeted augmentation and threshold calibration; achieved 97.76% on-floor inspection accuracy tracked across mAP, IoU, and recall.
  • Built as a complete end-to-end software pipeline — from raw camera feed to structured decision output — making the system operationally deployable rather than a prototype that only draws bounding boxes.
  • Operates fully on-premise with no cloud dependency, making it suitable for secure, air-gapped industrial environments where data sovereignty is a requirement.

On-premise deployment

SecureGPT

  • Architected a fully on-premise, no-internet enterprise AI platform — a system-sovereign solution where zero tokens, queries, or documents leave the private network, making it suitable for regulated industries and confidential enterprise data.
  • Built on a LangGraph multi-agent orchestration graph that routes queries to specialist agents (document Q&A, code generation, vision analysis, meeting summarisation); backed by hybrid retrieval (dense search + BM25) over a 7-lakh+ vector store, tested across 7,000+ real documents with 91% retrieval accuracy.
  • LLM-agnostic by design — easily swappable to any open-weight model (LLaMA, Mistral, Gemma) via Ollama with no code changes; department-level access control enforces corpus boundaries so each team queries only its own data.
  • LLM-generated code executes inside an isolated sandbox before being surfaced to users, and the entire stack runs on Docker for reproducible, auditable deployment in air-gapped enterprise environments.

XplainAI

  • Engineered an explainable multi-agent decision system for IIIT Pune's hackathon (PS01) — every query moves through an 11-stage agent graph covering intent detection, missing-context resolution, reasoning planning, live data collection from stock APIs, news feeds, and web search, multi-approach scoring, and final synthesis.
  • Delivers an interactive reasoning tree the user can navigate stage by stage — inspecting why each candidate answer was selected or rejected — enabling calibrated trust rather than blind acceptance of model output.
  • Built with a React frontend and Python agent backend; full-stack application designed so the transparency layer is part of the UX, not an afterthought.
  • Addresses the core limitation of most AI assistants: answers without auditability — XplainAI makes every reasoning step inspectable, from raw data collection through to the final ranked response.

2025RAG tutoring system
Personal project

PyMentor

  • Built an offline RAG-powered learning application that transforms any video lecture into a queryable knowledge source — audio extracted and transcribed via Whisper, chunked and embedded with BGE-M3, stored in a custom NumPy/Joblib vector index with no cloud dependency.
  • Cosine similarity retrieval grounds every answer in the actual transcript rather than the model's pretrained knowledge; LLaMA 3.2 runs locally via Ollama for fully private, on-device generation with ~1.3 seconds end-to-end latency.
  • Designed for students who need reliable, source-attributed answers from their own course material — a complete software pipeline from raw video to conversational Q&A, running entirely on consumer hardware.
  • Fully offline and data-sovereign — no API keys, no subscriptions, no data leaving the machine; any open-weight model can be swapped in via Ollama with a single config change.
